Trigger types

Website visitors

A pixel identifies anonymous traffic and turns matched visitors into mailable recipients. Page rules decide which campaign claims which visit.

Storm events

Hail and wind polygons arrive from HailTrace, get intersected with the service area, and the affected addresses become an audience the same day.

Radius mail

Drop a pin on a completed job and mail the surrounding blocks. Radius, quantity, and property filters are set per automation.

New movers

Weekly address-change data filtered to the service area, so the welcome card lands while the boxes are still unpacked.

CRM stage changes

A deal moving to a given stage fires a piece. Works from HubSpot, Salesforce, or anything that can call a webhook.

Custom webhooks

Post a payload with an address and a template id. Everything downstream — sanitization, suppression, print, mail — is handled.

Page rules decide the winner

When several automations sit on the same pixel, the one that named the visited page wins. An automation with no page rules is a fallback and only claims visits nothing else targeted.
